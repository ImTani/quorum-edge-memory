# Quorum showcase v3: director's storyboard + style bible

This is the single source of truth for every agent working on v3. **Don't change scene time ranges or key-event times.** The soundtrack is being composed against them in parallel. If a scene truly needs a different timing, report it and don't silently change it.

Output: 1920x1080, 30 fps, **150 s** total. No voiceover. On-screen text carries the story, so captions must be large, readable, and held long enough (~3 words/sec minimum reading time).

Product: **Quorum**, offline-first team memory on **Qdrant Edge**. Code Cubicle 6.0, Problem Statement 03. Repo: github.com/ImTani/quorum-edge-memory
Never mention ADHD. Never say "Jarvis". Names: Tanishk (laptop A, on a shoot), Lakshya (laptop B, in the studio), client "Sharma".

## Style bible

- **Mood:** premium dark tech motion graphics, like Linear/Vercel/Apple keynote. Calm, confident, precise. No clip-art or emoji faces.
- **Background:** #0A0E16 with a faint 60px grid (rgba(124,140,255,.05)) and a vignette. The ambient drifting 3D starfield/point-cloud is always subtly alive.
- **Colour semantics (never break these):**
  - amber `#F5A524` = local / queued / offline
  - green `#22C55E` = synced / resolved
  - red `#EF4444` = conflict / disputed
  - indigo `#7C8CFF` = UI accent / Qdrant / system
  - text `#E8ECF4`, secondary `#9AA4C0`, muted `#5B6478`
  - Superseded = grey + strikethrough. Kept, never deleted.
- **Type:** "Segoe UI Variable Display" / "Segoe UI" for text; Consolas for data/code. Hero words 120–200px bold with letter-spacing; captions 40–44px semibold on a dark rounded backing at the bottom (y≈958).
- **Motion:** everything eases (easeOutExpo for entrances, easeInOutCubic for moves, springs for pops). Stagger lists by 60–120ms. There are no hard cuts: scenes hand off with a 0.4–0.8s crossfade, a push, or a match-cut through the point cloud. Subtle constant camera drift (scale 1.00→1.03 over a scene) keeps it alive.
- **UI components:**
  - **Laptop windows** are macOS-style cards with three traffic-light dots, a title "Tanishk's laptop · on a shoot" / "Lakshya's laptop · in the studio", and a status pill at right (✈ Airplane mode · 0 B/s in amber, or ● Online in green).
  - **Cards:** rgba(20,26,40,.92), 1px indigo border at .28 alpha, radius 18, big soft shadow.
  - **Glows:** additive blending ('lighter') halos on points.
- **The 3D memory cloud is the recurring hero.** Each claim is a point in a 3D cloud (≈400 ambient points in a soft clustered galaxy shape with several semantic clusters), perspective-projected, slowly rotating, with depth-of-field (far points smaller and dimmer). The key points ("18th" note, "16th" email) are labelled with small leader-line tags.
